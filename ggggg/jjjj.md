git - Программа которая позволяет делать сохранения
git --version  - Комманда позволяет посмотреть версию гида

git status - Статус файлов

git add - позволяет написать название для сохр

git commit -m - позволяет написать комментарий

git log - позволяет узнать сохранения

git checkout № - Позволяет выбрать номер

git checkout master - Позволяет выбрать последнюю версию.
